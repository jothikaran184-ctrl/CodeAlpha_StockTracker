# Video Demo Script

## Project: CodeAlpha_StockTracker

### 30-second demo idea
- Open the terminal and run: `python StockTracker.py`
- Show the stocks list: AAPL, TSLA, GOOGL, MSFT, and AMZN.
- Enter sample stock symbols and quantities.
- Show the portfolio summary and total investment value.
- Optionally confirm that the user wants to save the summary to a file.

### Suggested narration
"This stock tracker lets the user add stock symbols and quantities to build a portfolio summary. It calculates the total value and can save the results to a text file for record keeping."

### Example sequence
1. Run the program.
2. Enter `AAPL` then `2`.
3. Enter `TSLA` then `1`.
4. Type `done`.
5. Confirm saving to a file.

### Recording note
Record the terminal screen while entering the stock inputs and showing the resulting summary.
